Video Player Rotation Test

Test Description

This test verifies that the video player properly rotates through all available ads in the pattern:

Ad 1, Default Video, Ad 2, Default Video, Ad 3, Default Video, ... then back to Ad 1

Test Implementation

The following changes were made to the video player:

  1. Modified initializePlaybackLoop() to properly create the alternating pattern
  2. Updated playNextInLoop() to handle proper rotation and loop completion
  3. Added logging to track the current position in the loop
  4. Improved handling of ads that can no longer be played (insufficient balance)

Expected Behavior

Test Scenario: 3 ads available
Expected Playback Order: Ad1 → Default → Ad2 → Default → Ad3 → Default → Ad1 → Default → Ad2 → Default → ...

Manual Testing Instructions

To manually test the video player rotation:

  1. Navigate to the video player page with a valid machineId
  2. Ensure multiple ads are assigned to the current time slot
  3. Enable debug mode by adding ?debug=true to the URL
  4. Observe the debug log to verify the playback pattern
  5. Check that each ad plays followed by the default video
  6. Verify that after the last ad, it returns to the first ad
  7. Monitor the console for "Completed full rotation" messages
